# 红果短剧 v1.0.1

> 好看的短剧尽在红果短剧

补丁版本：修复打包后的客户端**首页 Banner 推荐区不显示**的问题，并新增项目宣传页。安装包仍为 7 个：
Windows 10/11 的 x64 与 ARM64（安装版 + 免安装便携版，另有一个自动识别架构的通用安装器），
以及 macOS 的 Intel 与 Apple Silicon 版本。

## 系统支持范围

**支持的操作系统：Windows 10 与 Windows 11。**

| 系统 | 架构 | 支持情况 |
| --- | --- | --- |
| Windows 10 / 11 | x64（64 位） | 支持 |
| Windows 10 / 11 | ARM64 | 支持 |
| Windows 10 / 11 | x86（32 位） | 不提供：Electron 44 起上游不再发布 32 位 Windows 运行时 |
| Windows 7 / 8 | — | 不支持：Electron 已放弃这些系统 |

## 下载

| 文件 | 适用 |
| --- | --- |
| `HongGuo-PC-Setup-1.0.1.exe` | Windows 10/11 **通用安装器**（内含 x64 + ARM64，按机型自动选择） |
| `HongGuo-PC-Setup-1.0.1-win-x64.exe` | Windows 10/11 64 位安装器 |
| `HongGuo-PC-Setup-1.0.1-win-arm64.exe` | Windows 10/11 ARM64 安装器 |
| `HongGuo-PC-1.0.1-win-x64.zip` | Windows 10/11 64 位免安装便携版 |
| `HongGuo-PC-1.0.1-win-arm64.zip` | Windows 10/11 ARM64 免安装便携版 |
| `HongGuo-PC-1.0.1-x64.dmg` | macOS Intel |
| `HongGuo-PC-1.0.1-arm64.dmg` | macOS Apple Silicon |

> 文件名使用 ASCII：GitHub Release 的上传接口会剥离资产名中的非 ASCII 字符。
> 安装包内部与安装界面显示的产品名仍是「红果短剧」。

**Windows**：双击安装器即可，会自动弹出 UAC 申请管理员权限，不需要手动右键「以管理员身份运行」。

**macOS**：打开 dmg，把「红果短剧」拖进「应用程序」。未接入 Apple 开发者签名，
首次启动请「右键 → 打开」，或在「系统设置 → 隐私与安全性」中确认「仍要打开」一次。

## 本版本更新

### 修复

- **打包版首页 Banner 推荐区不显示**：抓取官方首页时若遇到一次网络抖动，空的推荐列表会被
  缓存 300 秒，而首页 Banner 只在启动时拉取一次，导致整个会话里都看不到推荐轮播
  （冷启动阶段最容易触发，开发模式因后端常驻难以复现）。现在空结果不再写入缓存。
- 同一问题可能影响首页四大专区与「全部榜单」，已一并加上同样的保护。
- **避免误连没有推荐接口的旧后端**：旧版客户端残留的服务也会应答健康检查但没有 Banner 接口，
  连上去同样看不到推荐区。现在启动时按能力探测，只会连接提供该接口的后端。
- 官方首页数据获取更稳：并发请求合并为一次抓取，失败自动重试一次，超时放宽至 10 秒；
  仍失败时沿用上一次可用的快照，而不是把空列表返回给界面。

### 新增

- 项目宣传页（`website/`）：深色配色，与桌面端保持同一套设计语言。

### 变更

- 发布流程文档与发布说明整理：按版本归档在 `docs/releases/`，每份说明都带版本号。
- 平台范围固定为 Windows（x64 / ARM64）+ macOS（Intel / Apple Silicon），每次发布 7 个资产。

## 已知问题

- 32 位 Windows 无安装包：Electron 44 起上游不再提供 32 位 Windows 运行时，保持现有 Electron 版本时无法产出。
- macOS 安装包未签名公证，首次启动需手动确认一次（见上方安装说明）。
- 部分安全软件会拦截本地服务端口或网络请求，导致首页内容为空；把本机后端端口加入放行即可恢复正常。
