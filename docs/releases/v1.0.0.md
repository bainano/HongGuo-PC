# 红果短剧 v1.0.0

> 好看的短剧尽在红果短剧

第一个正式版本，提供 Windows（安装版 / 免安装便携版）与 macOS（Intel x64 / Apple Silicon arm64）四套安装包。

## 下载

**支持的操作系统：Windows 10 与 Windows 11。**

| 文件 | 适用 |
| --- | --- |
| `HongGuo-PC-Setup-1.0.0.exe` | Windows 10/11 **通用安装器**（内含 x64 + ARM64，按机型自动选择） |
| `HongGuo-PC-Setup-1.0.0-win-x64.exe` | Windows 10/11 64 位安装器 |
| `HongGuo-PC-Setup-1.0.0-win-arm64.exe` | Windows 10/11 ARM64 安装器 |
| `HongGuo-PC-1.0.0-win-x64.zip` | Windows 10/11 64 位免安装便携版 |
| `HongGuo-PC-1.0.0-win-arm64.zip` | Windows 10/11 ARM64 免安装便携版 |
| `HongGuo-PC-1.0.0-x64.dmg` | macOS Intel |
| `HongGuo-PC-1.0.0-arm64.dmg` | macOS Apple Silicon |

> 文件名使用 ASCII：GitHub Release 的上传接口会剥离资产名中的非 ASCII 字符（中文会被吞掉）。
> 安装包内部与安装界面显示的产品名仍是「红果短剧」。

**关于 32 位（x86）Windows**：本版本不提供。Electron 44 起上游不再发布 32 位 Windows
运行时，本项目使用的 Electron 45 无法产出 32 位包；如需 32 位只能把 Electron 降到 43 及更早。
Windows 7 / 8 同样不支持（Electron 已放弃）。

**Windows**：双击安装器即可，会自动弹出 UAC 申请管理员权限（中文系统提示），
不需要手动右键「以管理员身份运行」。

**macOS**：打开 dmg，把「红果短剧」拖进「应用程序」。
因未接入 Apple 开发者签名，首次启动请**右键 → 打开**，或在
「系统设置 → 隐私与安全性」中确认「仍要打开」一次。

## 功能

- **首页**：推荐栏目 + 横幅轮播
- **分类**：真人剧 / 漫剧 / AI 剧
- **榜单**：红果热播榜、真人剧热播榜、AI 剧热播榜、漫剧热播榜
- **搜索**：关键词联想，剧集 / 关键词直达
- **详情与播放**：独立播放窗口，多清晰度、上下集、演员跳转
- **分享链接**：粘贴手机端分享口令，直接定位剧集与选集
- **窗口体验**：Windows 无边框自绘标题栏；macOS 使用系统原生红绿灯

## 本版本更新

### 新增

- **macOS 标题栏适配**：改用系统原生红绿灯按钮（`titleBarStyle: 'hidden'`），
  自绘三键在 macOS 下隐藏，标题栏左侧自动避让，双击标题栏空白处最大化。
- **macOS 构建支持**：内置构建工作流，可一键产出 Intel（x64）与 Apple Silicon（arm64）两个 dmg
  （手动触发，不在推送时自动运行）。
- **Windows 免安装便携版**：随 Release 附带 zip，解压即用。
- 版本号统一为 **1.0.0**。

### 修复

- **打包版播放报 502（UPSTREAM_UNAVAILABLE）**：Electron 内置 Node 使用 BoringSSL，
  不支持 SM3 摘要，而官方接口签名依赖 SM3，导致请求根本发不出去（开发环境用系统 Node 不会暴露）。
  新增纯 JS SM3 实现（`backend/shared/sm3.mjs`）与引擎沙箱 crypto 回退（`engine-crypto.mjs`）修复。
- **榜单页无法播放**：榜单接口只返回剧集 ID 与总集数，不带单集 ID。
  修复主窗口未向榜单页传入播放回调的问题，并改为点击集数时按需拉取剧集详情解析单集 ID（带缓存）后播放。
- **安装后启动黑屏**：打包时若 `vite build` 产物缺失，`app.asar` 中没有 `dist/index.html` 会导致黑屏。
  打包脚本现在强制先构建，并在出包后校验 asar 内容。
- **Windows 安装权限**：安装器改为 `perMachine`，自带管理员权限清单，双击即自动提权，
  不会再弹出英文的权限错误提示。
- **主窗口残留置顶、抢走其他应用焦点**：单独关闭播放窗口时主进程会临时把主窗口置顶以显示
  关闭确认弹窗，但该路径没有复位，导致之后主窗口永久位于最上层、其他窗口无法保持焦点。
  改为仅在真正进入「一键关闭全部」流程时才临时置顶，并在取消/确认/播放窗口销毁/超时（30s 看门狗）
  等所有结束路径统一撤销置顶。

### 变更

- 产品名称由 HongguoTV 正式更名为**红果短剧**，说明文案统一为「好看的短剧尽在红果短剧」。

## 已知问题

- macOS 安装包未签名/公证，首次启动需按上面说明手动放行一次。
- 播放清晰度依赖官方接口返回，个别剧集可能只有单一清晰度。
- 若本机已运行旧版（或其他占用 8788/8789 端口的红果相关服务），建议先退出，避免前端连到旧后端。
