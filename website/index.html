红果短剧 PC

开源的红果短剧第三方桌面客户端，复刻电脑网页版体验。 Windows 与 macOS 原生窗口，打开即用，可完整观看短剧。

下载客户端 查看源码

Windows 10 / 11　·　macOS　·　GPL-3.0　·　内容实时取自官方公开接口，本地不存储视频

项目介绍

红果短剧 PC 基于 Electron 与 React 实现，为 Windows 与 macOS 提供原生窗口， 内置本地内容服务，无需任何配置。按电脑网页版的信息结构组织内容——首页推荐、分类、榜单、搜索、详情与选集， 并用独立的播放窗口完成观看，让「在电脑上看短剧」回到熟悉、顺手的形态。

复刻网页版体验

首页推荐、分类、榜单、搜索、详情与选集，信息结构与电脑网页版一致。

完整观看短剧

独立播放窗口，多清晰度切换、上下集、自动连播，大屏一次看到底。

功能齐全

分享口令直达选集、无边框自绘标题栏、关闭播放窗口二次确认等细节一并具备。

功能

从浏览到播放的完整链路。

首页推荐

推荐栏目与横幅轮播，海报墙一屏浏览。

分类浏览

真人剧、漫剧、AI 剧分类切换，按题材找剧。

热播榜单

红果热播榜与各分类热播榜，追热剧不用搜。

搜索联想

关键词与剧集建议实时提示，回车直达详情。

详情与选集

剧集信息、演员与完整选集，点一集接着看。

播放器

多清晰度、上下集、自动连播，独立播放窗口。

分享链接直达

粘贴手机端分享口令或链接，直接跳到对应剧集与选集。

窗口体验

Windows 无边框自绘标题栏、macOS 原生红绿灯。

使用

从 Releases 下载对应平台的安装包，装上就能用；也可以用免安装便携版。

01

下载安装包

选择通用安装器（内含 x64 + ARM64，安装时自动匹配机型），或按机型选择专用包。

HongGuo-PC-Setup-<版本>.exe
02

安装或解压

双击运行并按提示完成安装，会自动申请管理员权限（UAC）；也可用 zip 便携版，解压后直接运行。

HongGuo-PC-<版本>-win-x64.zip
03

打开就看

启动后无需配置，客户端会自动拉起内置内容服务，浏览、搜索、点开即播。

01

下载 dmg

Intel 机型选 x64，Apple Silicon（M 系列）选 arm64。

HongGuo-PC-<版本>-arm64.dmg
02

拖入应用程序

打开 dmg，把「红果短剧」拖进「应用程序」文件夹。

03

首次打开确认

未接入 Apple 开发者签名，首次启动可能被 Gatekeeper 拦下：在「访达 → 应用程序」中右键 → 打开，再到「系统设置 → 隐私与安全性」确认一次即可。

系统支持范围

系统架构支持情况说明
Windows 10 / 11x64（Intel / AMD）支持主要目标平台
Windows 10 / 11ARM64（骁龙等）支持提供原生 ARM64 包
Windows 10 / 11x86（32 位）不提供Electron 44 起不再发布 32 位 Windows 运行时
Windows 7 / 8 / 8.1—不支持Electron 已放弃这些系统
macOSx64 / arm64附带提供未签名、未做适配验证，维护以 Windows 为准

说明

这是一个纯浏览与播放的客户端：不接入账号体系，也不做跨端同步。

不支持登录账号

客户端不提供、也不支持账号登录：没有登录入口，不需要账号密码，也不保存任何登录凭据。

不支持手机端内容同步

观看进度、收藏、历史不会与手机 App 互通或同步，也不做云端备份——电脑端是独立的一份使用记录。
